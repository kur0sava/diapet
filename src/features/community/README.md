# Сообщество / Чат (v2.6)

Международная мини-соцсеть внутри DiaPet: комнаты-форумы, real-time сообщения,
клиентская модерация + перевод в язык пользователя. Клиент реализован; часть
инфраструктуры деплоит владелец проекта (см. ниже).

План/решения: `.claude/plans/community-chat-plan-2026-07-18.md`.

## Что уже в коде (клиент)

- **Вкладка «ЧАТ»** (`ChatTab`) — species-reactive тема, RU/EN, только для
  залогиненных (Google → Firebase Auth уже в проекте).
- **12 комнат** (`data/rooms.ts`, MVP-набор 6), видовые теги, обоснованы
  форумами FDMB/k9diabetes.
- **Треды и сообщения** на Firestore (`api/communityApi.ts`): создание тем,
  real-time подписка (`onSnapshot`), отправка, жалобы, история.
- **Модерация — 1-й слой (клиент):** эвристики (`utils/moderation.ts` —
  абьюз/ссылки/контакты/дозы/флуд) + rate-limit (`utils/rateLimit.ts`,
  40/день + кулдаун 5с). Флаг → сообщение помечается `flagged` с мягким
  предупреждением.
- **Перевод** (`@shared/translation`): on-demand в язык юзера, кэш в MMKV,
  сохраняет названия лекарств/дозы/единицы без изменений. Едет на AI-прокси.
- **Правила сообщества** (`GuidelinesScreen`) — гейт перед первым постом.

## ⚠️ Что деплоит владелец (инфраструктура)

1. **Firestore security rules** — `firestore.rules` в корне.
   `firebase deploy --only firestore:rules` (проект `diapet-49162`).
   Без них чат небезопасен. Обязательно до продакшена.
2. **Составные индексы Firestore** — запросы тредов (`roomId` + `lastMessageAt`,
   и `authorUid` + `lastMessageAt`) требуют индексов. Firebase выдаст ссылку на
   создание при первом запросе, либо описать в `firestore.indexes.json`.
3. **AI-прокси (перевод + серверная модерация)** — Supabase Edge Function
   (та же, что для AI-ассистента). Пока `aiProxyUrl` пуст → перевод показывает
   «недоступно», серверная модерация не работает (клиентский слой работает).
   Задать `aiProxyUrl`/`supabaseAnonKey` в `eas.json`/`.env` после деплоя.
4. **Серверный AI-модератор (3-й слой)** — Cloud Function trigger на новые
   сообщения ИЛИ обработка очереди по `reportCount`/`moderation:'flagged'`.
   Модель «слоями»: AI только на подозрительное, не на весь поток.
