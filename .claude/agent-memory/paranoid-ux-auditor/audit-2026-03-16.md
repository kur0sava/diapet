# DiaPet v1.2.0 Adversarial UX Audit — 2026-03-16

## Summary: 5 Critical, 8 High, 18 Medium, 16 Low = 47 findings

## Key vulnerable areas:
- FeedCalculator: no input validation at all (negative, >100%, sum >100)
- AddExpenseScreen: no useUnsavedChangesGuard
- Onboarding PetInfoScreen: no maxLength on pet name
- AI Assistant: no rate limiting, no input sanitization
- Emergency screen: no VetPhone input validation
- DailyDiary add buttons don't pass date to log screens
- LogInjection: no NaN guard on dose field (decimal-pad allows non-numeric on some Android)
