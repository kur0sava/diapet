## Audit 2026-03-21: More, AI, Encyclopedia, FeedCalculator, Assessment

### Critical (1)
- BUG-020: SettingsScreen `handleDeleteAllData` -- MMKV keys deleted BEFORE SQL transaction. If SQL fails, app in inconsistent state (MMKV wiped, SQLite intact).

### High (4)
- BUG-021: SettingsScreen glucose unit change does NOT invalidate React Query cache -- medical risk
- BUG-015: AdvancedAnalyticsScreen pro-gate uses navigate+goBack simultaneously -- race condition
- BUG-005: AddExpenseScreen guard triggers falsely in edit mode (no isDirty pattern)
- BUG-014: EmergencyScreen "tapToAddVet" text is misleading -- tapping calls callVet() not settings

### Key Patterns Found
- AddExpenseScreen now HAS useUnsavedChangesGuard (was missing in prior audit), but implementation is wrong for edit mode
- AI chat has no "clear history" button
- FeedCalculator has no per-field inline validation for > 100%
- Several touch targets below 44px minimum (AI back button, trash icons, bookmark button)
- ExpensesScreen missing long-press-to-delete hint (SymptomsListScreen has it)
- PetProfileScreen: no empty state for empty schedules
